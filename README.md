# DermaHeal

## Project Description
DermaHeal is a simple Flutter mobile application that provides a Login and Registration interface for users. The project was developed as part of a Flutter assignment to practice widgets, layouts, text fields, buttons, navigation, password visibility, and basic form validation.

## Features

* Login page
* Registration page
* Email and password fields
* Full Name field
* Confirm Password field
* Show/Hide password
* Forgot Password option
* Login and Create Account buttons
* Navigation between Login and Registration pages
* Basic form validation
* Password matching validation

## How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Run the following command:

  flutter pub get

4. Start an Android emulator or connect an Android device.
5. Run the application using:

  flutter run

The DermaHeal application will then run on the selected device.
